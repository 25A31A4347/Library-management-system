# Library Management System (LMS)

A Library Management System (LMS) is an Enterprise Resource Planning (ERP) software designed to automate and manage the operations of a library.

The system streamlines core library functions such as acquisition, cataloging, circulation, and reporting, improving efficiency and reducing manual workload.

## Goal

The goal of this project is to streamline library operations, enhance user experience, and ensure efficient tracking and management of library resources.

## System Process

### User Login
Provides secure authentication and role-based access to the system.

### Search
Allows users to query the book database using details such as title, author, or category.

### Transaction
Handles book issue and return processes while maintaining borrowing records.

### Database Update
Ensures real-time updates to book availability and inventory.

## Core Modules

### Admin
- Manages the entire system  
- Adds and manages librarians  
- Generates reports  
- Maintains system settings  

### Librarian
- Issues and returns books  
- Manages student records  
- Calculates overdue fines  
- Updates book inventory  

### Student
- Searches for books  
- Views borrowing history  
- Checks due dates  
- Reserves books online  

## Benefits

- Improves time efficiency by reducing manual administrative work  
- Maintains data integrity and synchronized records  
- Reduces paperwork and operational costs  
- Provides insights into borrowing patterns and book usage
